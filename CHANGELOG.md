# Changelog

All notable changes to WolfgodRPG will be documented in this file.

## [1.0.0] - 2024-12-19

### 🎉 Major Release - Complete RPG System

#### ⚔️ Combat Mode System
- **Added**: Souls-like dash with double-tap directional controls
- **Added**: Smooth 360° rotation animation during dash
- **Added**: Multiple dashes with stamina management (up to 3)
- **Added**: Stun system when stamina depletes (2 seconds)
- **Added**: Combat mode toggle with hotkey
- **Added**: Visual feedback and particle effects

#### 🍎 Vitals System
- **Added**: Hunger system with natural decrease (1% per minute)
- **Added**: Sanity system with combat/darkness penalties
- **Added**: Stamina system with dual regeneration modes
- **Added**: Food restoration system with varying values
- **Added**: House detection for sanity regeneration
- **Added**: Starvation effects when hunger reaches 0%

#### 🏃 Movement Skills
- **Added**: Souls-like directional dash
- **Added**: Double jump unlocked at level 3
- **Added**: Wall jump unlocked at level 4
- **Added**: Stamina cost for all movement skills
- **Added**: Progressive skill unlocking system

#### 📊 RPG Systems
- **Added**: Player leveling with attribute points
- **Added**: Subclass system with unique abilities
- **Added**: Armor and weapon proficiency system
- **Added**: Experience tracking and notifications
- **Added**: Real-time vitals management

#### 🎯 Stamina Management
- **Added**: Natural regeneration outside combat mode
- **Added**: Automatic regeneration with hunger cost in combat
- **Added**: Stun penalty when stamina depletes
- **Added**: Dash blocking without sufficient stamina
- **Added**: Visual feedback for stamina status

#### 🍖 Hunger System
- **Added**: Natural decrease over time
- **Added**: Damage and speed modifiers based on hunger level
- **Added**: Food restoration from eating items
- **Added**: Starvation effects when reaching zero
- **Added**: Bonus damage at high hunger levels (70-100%)

#### 🏠 Sanity System
- **Added**: Decrease during combat or in darkness
- **Added**: Regeneration in houses and bases
- **Added**: Confusion effect when reaching zero
- **Added**: Defense penalty at low sanity levels
- **Added**: House detection with furniture recognition

#### 🎮 Enemy Food Drops
- **Added**: 15% chance for enemies to drop food
- **Added**: Various food items (Apple, Banana, Lemon, etc.)
- **Added**: Visual feedback when food drops
- **Added**: Integration with hunger restoration system

#### 🎨 Visual Effects
- **Added**: Particle effects during dash
- **Added**: Stun visual effects with particles
- **Added**: Screen feedback for vitals status
- **Added**: Smooth animations and transitions

#### 🔧 Technical Improvements
- **Added**: Modular system architecture
- **Added**: Event-driven update system
- **Added**: Performance optimizations
- **Added**: Multiplayer synchronization
- **Added**: Comprehensive error handling

#### 📱 UI/UX Enhancements
- **Added**: Real-time vitals display
- **Added**: Combat mode status indicators
- **Added**: Skill unlock notifications
- **Added**: Stun duration feedback
- **Added**: Food restoration messages

### 🐛 Bug Fixes
- **Fixed**: Stamina regeneration issues
- **Fixed**: Hunger not decreasing naturally
- **Fixed**: Sanity regeneration in houses
- **Fixed**: Dash animation glitches
- **Fixed**: UI update problems
- **Fixed**: Multiplayer synchronization issues

### 🔧 Configuration
- **Added**: Configurable stamina costs
- **Added**: Adjustable stun duration
- **Added**: Customizable vitals rates
- **Added**: Food drop chance settings
- **Added**: Visual effect toggles

### 📚 Documentation
- **Added**: Comprehensive README
- **Added**: Detailed wiki documentation
- **Added**: Code comments and documentation
- **Added**: Installation and setup guides
- **Added**: Troubleshooting section
